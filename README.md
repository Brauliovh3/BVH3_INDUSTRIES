# 🔮 BVH3 INDUSTRIES — Cyberpunk Portfolio

Portafolio web futurista (estilo cyberpunk) con navegación por secciones, partículas, terminal y un apartado de **Aplicaciones** con descarga de APK.

## ✨ Características

- UI cyberpunk (cyan + magenta) y efectos glow/glitch
- Secciones completas: Inicio, Perfil, Proyectos, Aplicaciones, Habilidades, Contacto
- Partículas en canvas + cursor effect (respeta `prefers-reduced-motion`)
- Descarga de APK desde la sección **Aplicaciones**

    ## Despliegue en Vercel

    Este es un sitio estático. Vercel puede desplegarlo directamente desde el repositorio, sin instalar dependencias ni ejecutar un comando de build:

    1. Importa el repositorio `BVH3_INDUSTRIES` en Vercel.
    2. Deja vacío el campo **Build Command**.
    3. Usa `./` como **Output Directory**.
    4. Pulsa **Deploy**.

    La configuración de cabeceras está en `vercel.json` y los experimentos de Habilidades se sirven desde `src/skills/`.
